# Pacing, Timing and Transitions

AI video clips are short (about 5 seconds). Design around this limit:

- **One Action Per Clip**: A 5-second clip holds exactly ONE clear action — 'she turns her head', not 'she enters, sits down and opens a book'.
- **Slow Pacing**: 'Slow deliberate movement, long take, contemplative pacing.' Slower action renders more cleanly than fast action.
- **Fast Pacing**: Build fast sequences from multiple short clips edited together, not one frantic prompt.
- **Montage**: Generate each montage beat as its own clip with consistent style, then cut them together.

Transitions between generated clips:

- **Hard Cut**: The default — cut on action for smooth flow.
- **Fade**: 'Fade to black' works as an edit between clips, not inside one.
- **Match Cut**: Repeat a shape or motion across two clips (a spinning plate → a spinning wheel).

Avoid asking for multiple scene changes inside one prompt — the model will morph the scene instead of cutting.
