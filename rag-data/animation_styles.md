# Animation and 3D Styles

For non-photorealistic videos, specify the exact medium — the renderer or studio style anchors the visual aesthetic strongly.

- **Anime Style**: 'Studio Ghibli style, 2D animation, vibrant colors, highly detailed backgrounds.'
- **3D Render**: 'Unreal Engine 5 render, Octane render, path tracing, raytraced reflections, highly detailed 3D.'
- **Pixar Style**: 'Pixar-style 3D animation, soft global illumination, expressive character design.'
- **Claymation**: 'Stop-motion claymation style, tactile textures, Aardman animations.'
- **Cyberpunk / Synthwave**: '80s retro anime, synthwave aesthetic, CRT monitor scanlines.'
- **2D Flat Animation**: 'Flat vector animation, bold shapes, limited color palette, motion graphics style.'
- **Pixel Art**: '16-bit pixel art animation, retro game aesthetic.'

Never mix styles (e.g. 'photorealistic anime') — contradictory style cues produce distorted, unsettling output.
