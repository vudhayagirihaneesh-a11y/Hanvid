# Subject and Character Consistency

To keep the same character across multiple generated clips:

- **Repeat the Full Description Every Time**: Do not use pronouns or 'the same man'. Write 'a bearded man in his 40s wearing a green flannel shirt and a gray beanie' identically in every clip of the sequence.
- **Lock 2-4 Distinctive Attributes**: Hair, age, clothing color, one accessory. These are the anchors the model actually preserves.
- **Keep Style Terms Identical Too**: If clip 1 says 'cinematic, teal and orange grade', clip 2 must repeat it — dropping style words lets the look drift.
- **Same Shot Type for Dialogue Scenes**: Alternate 'medium shot' and 'close-up' of the SAME description for a natural conversation rhythm.
- **Reference Image Beats Words**: For exact identity, use image-to-video with a reference frame of the character instead of text-only.

Sequences feel professional when subject + style vocabulary is copy-pasted verbatim between shots.
